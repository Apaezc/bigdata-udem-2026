Señalar cada columna resaltada y qué haría silver con ella.

Silver se construye con una consulta SQL que limpia y convierte tipos

ESTÁS AQUÍ

BRONZE

SILVER

GOLD

CREATE OR REPLACE TABLE silver.pedidos AS

SELECT pedido_id,

INITCAP(TRIM(cliente)) AS cliente,

TRY_TO_DECIMAL(REPLACE(monto, ',', ''), 10, 2) AS monto,

TO_DATE(fecha, 'DD/MM/YY') AS fecha

FROM bronze.pedidos

WHERE pedido_id IS NOT NULL; -- descarta filas rotas

Las tres líneas resaltadas convierten texto sucio en tipos confiables.
